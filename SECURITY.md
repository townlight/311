# Security

Townlight 311 is early-stage software. Current candidate version: `0.2.0`. This is source work only: it has not been installed or tested as an installed build, and it has not been released. Nothing here is a release claim. Do not deploy it as a system of record until a release explicitly says it is production-ready.

Report suspected vulnerabilities privately to the project maintainer. Do not open public issues containing exploit details, secrets, or sensitive municipal data.
