## Welcome to Townlight 311

Townlight 311 is the Townlight module for resident service request intake, deterministic triage, duplicate-candidate review, department routing, and Open311-compatible export checklists.

## What v0.1.0 ships

The first release is intentionally narrow. It proves the package, API, documentation, browser QA, and release gates while keeping official dispatch, emergency response, work-order creation, legal advice, 311 system write-back, and system-of-record updates with staff.
