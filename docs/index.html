Townlight / Townlight 311

Resident requests routed without black-box dispatch.

Townlight 311 is the Townlight module for resident service-request intake, privacy-aware tracking, staff workflow, records, notifications, and Open311-compatible interchange. This page describes the 0.2.0 source candidate: source work under integration, not an installed, verified, or shipped build.

0.2.0 source candidate — not installed, verified, or shipped

What this candidate implements

  • Private resident intake, tracking, recovery, and photos.
  • Staff queues, lifecycle, assignment, transfer, duplicate handling, and reopen.
  • Real SMTP notification states (sent, pending, failed, uncertain).
  • CSV/JSON import with exact preview.
  • Supported, authenticated Open311 subset.
  • Records archive handoff and approved Data.
  • Verified parcel, permit, and inspection links.

Existing native roles

The candidate enforces the existing native roles:

  • local-admin
  • city-staff
  • clerk

Clerk gets 311 only; Records/Data receiving requires additional permissions.

What is not included

Townlight 311 does not dispatch crews, create official work orders, handle emergencies, provide legal advice, call live LLMs, write back to 311 systems, or replace a 311 system of record. Communications and Parks features are not finished and are not promised by this candidate.

FAQ: What does “source candidate” mean?

Q: Is this a finished or released product?
No. “0.2.0 source candidate” means the 0.2.0 source work exists in the repository under integration verification. It has not been released, and it has not been tested as an installed Windows build.

Q: Can I install or rely on it?
Not as a supported build. Nothing here is a shipped, supported, or acceptance-tested product. Use the existing Suite 1.9.3.2 release for current use; it does not contain Townlight 311.

Q: Does it replace a 311 system of record?
No. It supports intake, tracking, staff workflow, records, notifications, and a supported Open311 subset, but it is not full Open311 conformance and does not replace a system of record.

Q: Are delivery and integrations guaranteed?
No. Notification delivery is not guaranteed, and integrations such as communications and Parks are not finished by this candidate.
